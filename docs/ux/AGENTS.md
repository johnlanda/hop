# HOP terminal UX

## Purpose

Describe HOP's proposed terminal interactions inside Herdr. Mockups are conceptual,
not screenshots or implemented UI. Distinguish Herdr-owned chrome and native
agent terminals from HOP-rendered content.

## Map

- [Pane workflows](panes.md): layouts, navigation, attention, review and accounts.
- [Architecture](../architecture/AGENTS.md): application and adapter boundaries.

Keep controls scoped to the terminal surface receiving input. Do not imply that
HOP can add native sidebar widgets or tile panes from different workspaces without
moving them. Account labels are examples, never actual credentials.
